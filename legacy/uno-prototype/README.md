# 試作 1 号機（Arduino Uno 版）

QuakeScope の出発点になった、最初の「地震即時アラートシステム」のスケッチです。記録のため、**当時のまま**残しています（`Seismometer_main_unit.ino`）。このスケッチは今の QuakeScope では使いません。

## 構成

| 部品 | 役目 |
|---|---|
| Arduino Uno | 揺れの計算・表示・警報 |
| アナログ出力の 3 軸加速度センサー（A0〜A2） | 揺れを測る |
| DS3231（RTC） | 時刻 |
| SSD1306 OLED 128×32 | 揺れのグラフ・時刻 |
| ESP-01S（SoftwareSerial、別のスケッチ） | 通知 |
| LED・ブザー | 警報 |

## 作り直すときに見つけた問題と、QuakeScope での対処

| 試作 1 号機 | 何が起きるか | QuakeScope |
|---|---|---|
| `if (shakeMagnitude <= SHAKE_THRESHOLD_S)` のように、**比べる向きが逆** | 揺れていないとき（値が小さいとき）に警報になり、揺れると止まる | 揺れの大きさが基準を**超えた**ときに判定。テストで確かめている |
| `maxShake` を `<` で更新し、初期値が 1.0 | 「最大」に最小値が入る | この揺れの最大を、0.3 秒の基準どおりに求める |
| P 波・S 波を、揺れの**大きさ**のしきい値で分けている | P 波・S 波は届く順番の違いなので、大きさでは区別できない | P 波はふだんとの比（STA/LTA）でとらえ、強さは震度相当で段階を分ける |
| 合成加速度と 1 G の差を「揺れ」とする | 傾きやセンサーの誤差で、揺れていなくても値が出る。横揺れが小さく出る | 起動時に重力の向きを 3 方向で測って引く（どの向きに置いても動く） |
| `delay(50)` と画面の描画で、読む間隔が 50 ms 以上・不ぞろい | 周波数を使う震度の計算ができない | センサーの FIFO で 100 Hz ちょうどに読む（別のタスク） |
| ESP-01S に文字を送るだけ | 通知が届いたか分からない | ESP32 1 枚で、HTTPS の応答を見て送り直す。結果を履歴に残す |
| しきい値が加速度（G）の固定値 | 体感の震度と結びつかない | 気象庁の計測震度と同じ考え方で計算した「震度相当」 |

試作で「揺れを感じたら知らせる」流れを形にできたことが、そのまま QuakeScope の設計の土台になっています。
