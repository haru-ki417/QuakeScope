# 使い方

QuakeScope は、置いた場所の揺れを測り、気象庁の「計測震度」と同じ考え方で計算した**震度相当**を出す揺れ検知アラームです。強い揺れでは警報音を鳴らし、スマホに通知を送ります。

> 本機の値は、置いた場所で測った揺れからの**推定（参考値）**です。気象庁の発表する震度・緊急地震速報ではありません。揺れを感じたら、まず身の安全を確保してください。

## はじめの設定

初めて電源を入れると、本体が自分の Wi-Fi を出して「設定モード」になります（LED が青く点滅）。

1. 本体の画面に、次のように出ます。
   ```
   SETUP  connect to:
   QuakeScope-1A2B
   PASS 12345678
   then open
   http://192.168.4.1
   ```
2. スマホの Wi-Fi 設定で `QuakeScope-1A2B` を選び、`PASS` のあとの 8 けたを入れます（本体ごとに違います）。
3. 設定の画面が自動で開きます。開かないときは、ブラウザーで `http://192.168.4.1` を開きます。
4. 次の 4 つを入れて「保存して再起動」を押します。
   - **Wi-Fi のネットワーク**（2.4 GHz のもの。ESP32 は 5 GHz につなげません）と **パスワード**
   - **置く場所の名前**（通知の文に入ります。例: リビング）
   - **設定用のパスワード**（8 文字以上。あとで設定を変えるときに使います）
5. 本体が再起動して家の Wi-Fi につながると、LED がゆっくり緑に明滅します。

設定をやり直すときは、ボタンを押しながら電源を入れると、設定モードに入ります。

## 設定の画面を開く

スマホやパソコンを本体と同じ Wi-Fi につないで、ブラウザーで次のどちらかを開きます。

- `http://QuakeScope-1A2B.local/`（`1A2B` は本体ごとに違う。画面の 2 行目と同じ）
- 本体のボタンを短く押すと、画面に IP アドレスが出ます。`http://192.168.1.23/` のように開きます

| タブ | できること |
|---|---|
| いまの揺れ | いまの震度相当・この揺れの最大・最大加速度・直近の波形 |
| 記録 | これまでの揺れの一覧（最大 50 件）。行を押すと、その揺れの波形（新しい 8 件まで） |
| 通知の履歴 | 送った通知と、成功したか（最大 20 件） |
| 設定 | 警報の目安・音の大きさ・通知先（設定用のパスワードが要ります） |
| 本体 | Wi-Fi の強さ・空き容量・センサーの状態・警報音のテスト・向きを測り直す・記録を消す・初期状態に戻す |

## 本体の画面

```
12:34:56        W      ← 時刻、W = Wi-Fi につながっている（- = つながっていない）、M = 音を消している
SHINDO 4               ← 揺れているとき: 震度相当（5-=5弱、5+=5強）。いつもは NORMAL
NOW 2.6   MAX 3.9      ← いまの値と、この揺れの最大（計測震度相当）
▁▂▅▇▅▃▂▁               ← 直近 12.8 秒の揺れの大きさ
```

注意・警報のときは、2 行目が白黒反転します。

## LED の色

| 色 | 意味 |
|---|---|
| 緑（ゆっくり明るさが変わる） | 平常。見張っている |
| 水色 | 準備中（電源を入れてから約 15 秒、向きと雑音を測っている） |
| 黄 | 揺れを検知（震度 1 相当以上） |
| 橙の点滅 | 注意（初期設定では震度 3 相当以上） |
| 赤の速い点滅 | 警報（初期設定では震度 5 弱相当以上） |
| 紫の点滅 | センサーの異常（値が止まった・重力の大きさがおかしい・値が届かない） |
| 青の点滅 | 設定モード |

## 音

| 音 | いつ | 長さ |
|---|---|---|
| ピピッ | 揺れを検知 | 一瞬 |
| ピー・ピー（くり返し） | 注意 | 30 秒 |
| ピポピポ（高い音・くり返し） | 警報 | 60 秒 |

ボタンを短く押すと止まります。音の大きさは設定の画面で 0〜100 にできます（0 にすると鳴りません。画面に `M` が出ます）。

## ボタン

| 押し方 | すること |
|---|---|
| 短く押す | 鳴っている警報音を止める。鳴っていなければ、名前・IP アドレス・版を 5 秒表示 |
| 3 秒押して離す | 警報音のテスト |
| 10 秒押して離す | 初期状態に戻す（Wi-Fi・通知先・記録をすべて消す）。10 秒で画面に確認が出る |
| 押しながら電源を入れる | 設定モード |

## 警報の目安

設定の画面の「警報の目安」で変えられます。

| 項目 | 初期設定 | 選べる値 |
|---|---|---|
| 注意（警報音・通知） | 震度 3 相当（計測震度 2.5） | 震度 2〜4 相当 |
| 警報（強い警報音・通知） | 震度 5 弱相当（計測震度 4.5） | 震度 4〜5 強相当 |
| 通知する揺れ | 注意から | 注意から・警報だけ |

- 1 回の揺れで、同じレベルの通知は 1 度だけ送ります。揺れが収まると「おさまりました」のまとめを送ります（通知した揺れのときだけ）。
- 通知は 1 時間に 12 通までにしています（壊れたときに送り続けないように）。**警報は、この上限に関係なく送ります。**

## 通知

LINE・Telegram・Discord・メールに送れます。いくつでも同時に使えます。設定のしかたは[通知の設定](notifications.md)を見てください。設定の画面の「テスト通知を送る」で、届くか確かめられます。

## 揺れの記録

- 揺れるたびに、最大の震度相当・最大加速度・続いた時間・揺れ始めの時刻を残します（最大 50 件。古いものから消えます）。
- 揺れ始めの 5 秒前からの波形（3 方向、毎秒 50 回）を、新しい 8 件まで残します。
- 記録は本体の中だけにあり、外には送りません。

## ファームウェアの更新

設定の画面の「本体」タブの `/update` を開き、ユーザー名 `admin` と設定用のパスワードを入れて、新しいファームウェア（`.bin`）を選びます。Arduino IDE の「スケッチ」→「コンパイル済みバイナリをエクスポート」で作れます。

## 置き場所と精度

- **建物の柱の近くの床**や、**壁に固定したたな**に、耳をねじで留めるのがいちばん正確です。置いただけだと、強い揺れで本体がずれて、値が乱れます。
- 気象庁の震度計は地面や低い建物の 1 階に置かれています。**高い階や、たなの上では、気象庁の震度より大きく出る**ことがあります。
- 本体のセンサー（MPU6050）は雑音が大きく、置いておくだけで震度 1.5 相当ほどの値が出ます。本体はこの「平常時の値」を測り続け、それより十分大きい揺れだけを揺れとみなします。そのため、**震度 2 相当以下の小さな揺れは見逃すことがあります。** 震度 3 相当以上の揺れの判定には影響しません。
- 電源を入れてから約 15 秒は準備中で、揺れを判定しません。

## 停電と通信

- 停電すると、本体も Wi-Fi のルーターも止まります。給電しながら充電できるモバイルバッテリーをつなぐと、本体は動き続けて警報音を鳴らせます（ルーターが止まると通知は届きません）。
- インターネットが混み合うと、通知が遅れたり届かなかったりします。本体は 3 回まで送り直します。**通知だけに頼らないでください。**

## 困ったとき

| 症状 | すること |
|---|---|
| 家の Wi-Fi につながらない（画面に `-`） | 2.4 GHz のネットワークか。パスワードの大文字・小文字。ボタンを押しながら電源を入れて、設定し直す |
| 通知が届かない | 「通知の履歴」でエラーを見る。「テスト通知を送る」を押す。[通知の設定](notifications.md#うまくいかないとき) |
| 何もないのに検知する | 洗濯機・エアコンの室外機・道路の近くなど、いつも揺れている場所を避ける。たなに置いているなら床へ |
| 時刻が出ない | インターネットにつながると、自動で合います（NTP） |
| 設定用のパスワードを忘れた | ボタンを 10 秒押して初期状態に戻し、設定し直す |
