# 組み立てと書き込み

はんだ付けが初めてでも、3〜4 時間で組み立てられる量です。部品は[部品表](../hardware/BOM.md)、つなぎ方は[回路図](../hardware/schematic.svg)と[基板の配置と配線表](../hardware/wiring.md)を見てください。

![組み立てたケースの中](../hardware/case/preview-inside.png)

## 1. ケースを 3D プリントする

| ファイル | 向き | 設定の目安 |
|---|---|---|
| [case_base.stl](../hardware/case/case_base.stl) | 底を下 | PLA か PETG・0.2 mm・壁 3 周・充填 20%・サポートなし |
| [case_lid.stl](../hardware/case/case_lid.stl) | 表（平らな面）を下 | 同じ |

- 印刷に 4〜5 時間かかります。
- ふたがきついときは、`hardware/case/case.mjs` の `fit` を 0.4 に、ゆるいときは 0.2 にして作り直します（下の「ケースの寸法を変える」）。
- OLED は製品によって寸法が少しずつ違います。手元の OLED の基板の大きさを測って、`oled` の `w`・`h` を合わせてください。

### ケースの寸法を変える

```sh
cd hardware/case
npm install          # manifold-3d（ケースを作る計算のライブラリ）を入れる
node case.mjs        # case_base.stl と case_lid.stl を作り直す
```

基板の部品の位置を変えたときは、先に `python3 tools/hw/layout.py` で `hardware/layout.json` を作り直します。ブザーの音の穴などは、この配置に合わせて開きます。

## 2. 基板を作る

![基板の配置と配線](../hardware/perfboard.svg)

1. **低い部品から**付けます。抵抗（R1〜R5）→ ダイオード（D1、帯を 5V 側）→ トランジスター（Q1、平らな面を手前）→ 電解コンデンサー（C1、足の長い方が +）→ ブザー（BZ1、+ の印を 5V 側）。
2. **ピンソケット 2 本**を付けます。ESP32 を挿したまま付けると、間隔がずれません（ESP32 の足は熱で傷まない程度に、手早く）。
3. **L 型ピンヘッダー**（J3・J4・J5）を、足が基板の外側を向くように付けます。
4. **加速度センサー（U2）**: ピンヘッダーの黒い台を抜いて、センサーの基板を低く付けます。センサーと基板のすき間に、クッションのない薄い両面テープを挟んで密着させます。**ここが浮いていたりぐらついたりすると、本当の揺れより大きく測ります。**
5. [配線表](../hardware/wiring.md)の順に、はんだ面で配線します。1 本ごとにテスターで導通を確かめ、表に印をつけていくと抜けがありません。
6. 最後に、**5V と GND、3.3V と GND がつながっていない**ことをテスターで確かめます（つながっていたら、どこかでショートしています）。

## 3. ふたの部品を付ける

| 部品 | 付け方 | 基板とのつなぎ |
|---|---|---|
| OLED（U3） | ふたの裏のくぼみに入れ、四隅をホットボンドで留める | ジャンパーワイヤーで J3（GND・VCC・SCL・SDA の印刷どおりに） |
| LED（LED1） | ふたの裏から穴に押し込み、ホットボンドで留める | 足にジャンパーワイヤーを挿して J4（R・G・B・いちばん長い足が K） |
| 押しボタン（SW1） | 前の壁の穴に通し、ナットで締める | J5（どちらの足でもよい） |

OLED は、ピンヘッダーを付けずに線をじかにはんだ付けすると、薄く収まります。

## 4. ファームウェアを書き込む

1. [Arduino IDE 2](https://www.arduino.cc/en/software) を入れます。
2. **ボードマネージャー**で「esp32 by Espressif Systems」（3.3 以降）を入れます。
3. **ライブラリマネージャー**で「Adafruit SSD1306」を入れます（Adafruit GFX と Adafruit BusIO も一緒に入ります）。
4. `firmware/QuakeScope/QuakeScope.ino` を開きます。
5. 「ツール」で次のように選びます。
   - ボード: **ESP32 Dev Module**
   - Partition Scheme: **Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**（これを選ばないと、大きすぎて書き込めません）
   - ポート: ESP32 をつないだときに増えたもの
6. 「書き込み」を押します。

コマンドで書き込むときは:

```sh
arduino-cli compile --fqbn esp32:esp32:esp32:PartitionScheme=min_spiffs firmware/QuakeScope
arduino-cli upload  --fqbn esp32:esp32:esp32:PartitionScheme=min_spiffs -p <ポート> firmware/QuakeScope
```

2 回目からは、本体の設定画面の「本体」タブから、Wi-Fi 経由で書き込めます（[使い方](manual.md#ファームウェアの更新)）。

## 5. 動かしてみる

1. USB をつなぐと、画面に `QuakeScope v1.0.0 CALIBRATING` と出て、短い音が鳴ります。
2. 画面に `SETUP connect to:` と出たら成功です。[使い方](manual.md)の「はじめの設定」に進みます。

| 症状 | 確かめること |
|---|---|
| 画面が真っ暗 | OLED の VCC と GND が逆になっていないか。SDA と SCL が入れ替わっていないか |
| 画面に `NO SENSOR` | U2 の SDA・SCL・VCC・GND。AD0 が GND につながっているか |
| LED が紫に点滅 | センサーの値がおかしい（[使い方](manual.md#led-の色)） |
| 音が鳴らない | ブザーが「発振回路なし」か。Q1 の向き（E・C・B） |
| 書き込みで止まる | ESP32 の BOOT ボタンを押したまま、書き込みを始める |

## 6. 置く

- **建物の柱の近くの床**か、**壁に固定した、がたつかないたな**に、耳を木ねじで留めます。ねじが使えないときは、強力な両面テープで。
- 置いたら、本体が向きを測り直すまで（電源を入れてから約 15 秒）動かさないでください。
- 傾いていても、どの向きでも動きます（重力の向きを自分で測ります）。壁に縦に付けることもできます。
- 高い階や、たなの上では、建物やたなが揺れを大きくするため、気象庁の震度より大きく出ることがあります。
