# 通知の設定

QuakeScope は、注意・警報の揺れと、揺れがおさまったときのまとめを、次の 4 つに送れます。いくつでも同時に使えます。

| 送り先 | 用意するもの | 費用 | 向いている人 |
|---|---|---|---|
| [LINE](#line) | LINE 公式アカウント（Messaging API） | 月 200 通まで無料 | 家族みんなが LINE を使っている |
| [Telegram](#telegram) | Bot のトークンとチャット ID | 無料 | 設定がいちばん簡単 |
| [Discord](#discord) | Webhook の URL | 無料 | 家族やチームのサーバーがある |
| [メール](#メールgmail) | Gmail のアプリ パスワード | 無料 | どの端末でも受け取りたい |

届く文の例:

```
【揺れを検知】リビングで震度3相当の揺れを検知しました。
時刻: 2026/10/5 14:23:07
※本機が測った揺れからの推定値です。気象庁の発表する震度ではありません。
```

```
【揺れがおさまりました】リビング 最大震度3相当
揺れ始め: 2026/10/5 14:23:07
揺れていた時間: 約41秒
最大加速度: 52 gal
計測震度（推定）: 3.4
※本機が測った揺れからの推定値です。気象庁の発表する震度ではありません。
```

設定した値は、本体の中（ESP32 の不揮発メモリー）だけに保存します。設定の画面には、保存した値を表示しません（「設定済み」とだけ出ます）。

## LINE

以前の「LINE Notify」は 2025 年 3 月 31 日で終わったため、**LINE 公式アカウントの Messaging API** を使います。自分専用の公式アカウントを作り、そこから自分（や家族）に送る形です。

1. [LINE 公式アカウント](https://entry.line.biz/start/jp/)を作ります（無料のコミュニケーションプラン）。
2. [LINE Official Account Manager](https://manager.line.biz/) で、作ったアカウントの「設定」→「Messaging API」→「Messaging API を利用する」を押します。プロバイダーは新しく作ってかまいません。
   - 2024 年 9 月 4 日から、LINE Developers コンソールで Messaging API のチャネルを直接作ることはできなくなっています。この手順で作ります。
3. [LINE Developers コンソール](https://developers.line.biz/console/)を開き、同じプロバイダーの中のチャネルを選びます。
4. 「Messaging API 設定」タブの下の方で、**チャネルアクセストークン（長期）**を「発行」してコピーします。
5. 「チャネル基本設定」タブの**あなたのユーザー ID**（`U` から始まる 33 文字）をコピーします。
6. 「Messaging API 設定」タブの QR コードを、通知を受けたい LINE で読み、**友だちに追加**します。
7. QuakeScope の設定の画面の「通知」→「LINE」に、4 のトークンと 5 のユーザー ID を入れて保存し、「テスト通知を送る」を押します。

**無料で送れるのは月 200 通まで**です（コミュニケーションプラン。上限を超えると送れなくなり、エラーになります）。通常の使い方（1 回の揺れで 2〜3 通）なら足ります。家族にも送りたいときは、Telegram の グループや Discord を使うと通数を気にせずに済みます。

参考: [Messaging API を始めよう](https://developers.line.biz/ja/docs/messaging-api/getting-started/)・[Messaging API の料金](https://developers.line.biz/ja/docs/messaging-api/pricing/)

## Telegram

1. Telegram で [@BotFather](https://t.me/BotFather) を開き、`/newbot` を送ります。名前を 2 回聞かれるので答えると、**Bot のトークン**（`123456789:AA...`）が届きます。
2. 作った Bot を開き、何か 1 通送ります（「こんにちは」など）。
3. ブラウザーで `https://api.telegram.org/bot<トークン>/getUpdates` を開き、`"chat":{"id":` のあとの数字をコピーします。これが**チャット ID** です。
   - 家族のグループに送りたいときは、Bot をグループに入れて、グループで 1 通送ってから同じページを開きます（グループの ID は `-` から始まります）。
4. QuakeScope の設定の画面の「通知」→「Telegram」に、トークンとチャット ID を入れて保存し、「テスト通知を送る」を押します。

## Discord

1. 通知を受けたいサーバーの、チャンネルの歯車（チャンネルの編集）→「連携サービス」→「ウェブフック」→「新しいウェブフック」を押します。
2. 名前を「QuakeScope」などにして、「ウェブフック URL をコピー」を押します。
3. QuakeScope の設定の画面の「通知」→「Discord」に URL を入れて保存し、「テスト通知を送る」を押します。

## メール（Gmail）

Gmail は、ふだんのパスワードでは送れません。**2 段階認証を有効にしたうえで、アプリ パスワード**を作ります。

1. Google アカウントの「セキュリティ」で、**2 段階認証プロセス**を有効にします。
2. Google アカウントの検索欄で「アプリ パスワード」を探して開き、名前（QuakeScope）を入れて作ります。16 文字のパスワードが出ます。
3. QuakeScope の設定の画面の「通知」→「メール」に、次のように入れます。

| 項目 | 値 |
|---|---|
| SMTP サーバー | `smtp.gmail.com` |
| ポート | `465（SSL）`（つながらなければ `587（STARTTLS）`） |
| ユーザー名 | 自分の Gmail アドレス |
| パスワード | 2 の 16 文字（空白は入れない） |
| 宛先 | 受け取るアドレス（カンマで区切って複数） |

4. 保存して「テスト通知を送る」を押します。迷惑メールに入ることがあるので、最初は迷惑メールのフォルダーも見てください。

ほかのメールサービスでも、SMTP（465 か 587、ユーザー名とパスワードで認証）に対応していれば使えます。

## うまくいかないとき

設定の画面の「通知の履歴」に、送った結果が出ます。

| 出る内容 | 原因と対処 |
|---|---|
| `401` | トークンやパスワードが違う。コピーし直す（前後の空白に注意） |
| `400`（LINE） | ユーザー ID が違うか、Bot を友だちに追加していない |
| `400`（Telegram） | チャット ID が違うか、Bot に 1 通も送っていない |
| `404`（Discord） | ウェブフックが消されている。作り直す |
| `429` | 送りすぎ。しばらくすると送れる（本体は自動で送り直す） |
| 接続できない | 本体がインターネットにつながっているか。時刻が合っているか（画面の時計） |
| `535`（メール） | 認証の失敗。アプリ パスワードを使っているか。2 段階認証が有効か |
